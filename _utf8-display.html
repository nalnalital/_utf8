⚠️ Compatibilité Emojis

Caractères en carrés (□) ou invisibles : Non supportés par votre navigateur/système

Pourquoi certains emojis ne s'affichent pas ?

  • Plages Unicode étendues : La plage "Miscellaneous Symbols And Pictographs" (0x1F300-0x1F5FF) a été créée en Unicode 6.0 (2010), mais elle a été étendue dans les versions suivantes (7.0, 8.0, 9.0, etc.)
  • Exemples : 🎔 (U+1F394), 🎕 (U+1F395), 🕀 (U+1F540) sont dans cette plage mais ont été ajoutés après Unicode 6.0, donc ils nécessitent des versions plus récentes
  • Police emoji obsolète : Apple Color Emoji, Segoe UI Emoji, etc. doivent être à jour pour inclure ces extensions
  • Solution : Mettre à jour macOS/iOS, Windows, ou utiliser une police emoji récente (Noto Color Emoji)

Rendu des emojis :

  • Polices emoji : Les emojis sont rendus par des polices spéciales (emoji fonts)
  • Propre au navigateur/OS : Chaque système utilise sa propre police emoji (Apple Color Emoji, Segoe UI Emoji, Noto Color Emoji, etc.)
  • Police locale : On peut charger une police emoji en local (ex: Noto Color Emoji, Twemoji) pour un rendu cohérent
  • Avantage : Rendu identique sur tous les navigateurs, même sans support natif

Compatibilité approximative :

  • Emojis Unicode 6.0-8.0 (2010-2015) : ~95-98% de compatibilité (Chrome, Firefox, Safari, Edge modernes)
  • Emojis Unicode 9.0-11.0 (2016-2018) : ~85-90% de compatibilité
  • Emojis Unicode 12.0-14.0 (2019-2021) : ~70-80% de compatibilité
  • Emojis Unicode 15.0+ (2022+) : ~50-60% de compatibilité (nécessite mises à jour récentes)
  • Symboles & Dingbats (noir & blanc) : ~98-99% de compatibilité (très anciens, largement supportés)

Recommandation : Utilisez les emojis de la section "Noir & Blanc" pour une compatibilité maximale, ou les emojis colorés Unicode 6.0-8.0 pour un bon équilibre. Pour un rendu cohérent, chargez une police emoji locale (Noto Color Emoji, Twemoji).

Structure des polices emoji :

  • Code point Unicode (ID) : Identifiant numérique unique (ex: U+1F600 pour 😀)
  • Nom Unicode formel : Nom standard défini par Unicode (ex: "GRINNING FACE")
  • Nom de glyphe (psname) : Nom interne à la police (variable selon la police, ex: "uni1F600" ou "grinning_face")
  • Résultat : La police mappe le code point → nom de glyphe → glyphe visuel
